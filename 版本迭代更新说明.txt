图像帧序列查看器（UE）——版本迭代更新说明（降序）
================================================

v3.7.1（当前最新版，2026-10-12）
- Mac 与 Windows 启动器名称增加平台标识。
- 按当前项目规则将“漏光”归入构图问题，并兼容导入旧 CSV 光影列中的“漏光”。
- 修复切换目录清空未导出标注，保存取消、导出失败、扫描失败和列表构建失败时保留旧文档。
- 修复 CSV 备注往返丢失和“漏光”迁移误匹配备注的问题，保留八列结构及旧 CSV 导入。
- 修复跨序列撤销污染备注、输入上下键误导航、损坏图片显示旧帧的问题。
- 修复更改质检人未更新导出状态、日志不可写时中断原异常处理的问题。
- 增加 Linux/Windows 真实 Tk 回归测试，并修复 Windows 启动器退出码传播。
- 含转义备注的新版 CSV 应使用 v3.7.1 或更新版本读取；上一稳定版 v3.7.0 ZIP 归档到“历史版本”。

v3.7.0（上一稳定版）
- 调整主界面信息层级：左右侧栏采用一致的初始宽度，移除文件树横向滚动条。
- 标签文本框默认保持单行，并根据自动换行后的实际可见行数自动增长或收缩。
- 双击图片可在系统文件管理器中打开所在目录并定位文件。
- 展开序列时以可中断短动效将目标项滚动到视区中部，并兼容减少动态效果。
- 增加 macOS 与 Windows 双击启动器，精简运行日志，仅在错误发生时生成诊断日志。
- 收敛 Tk/mixin 动态属性类型问题，全项目 mypy 达到零错误，并增加 Windows CI 验证。
- 清理未使用的 UI 配置与组件工厂；发布包排除分析缓存、日志、测试和内部工具。
- 使用正式 Git Tag `v3.7.0` 与 GitHub Release 发布，v3.6.1 ZIP 已归入本地“历史版本”。

v3.6.1
- CSV 导入采用事务式提交，异常时不再遗留部分修改。
- CSV 导出采用同目录临时写入和原子替换，失败时保留旧文件。
- 文件夹扫描改为后台执行，支持进度、取消、资源上限和分批构建树节点。
- 增加图片像素、CSV 大小/行数、目录项目/深度及渲染结果队列上限。
- 补充静态检查、依赖审计、GUI 验收、发布清单、Git Tag 和 Release 流程。

v3.6
- 按 v3.6 当时的业务规则，将“漏光”调整为从光影问题列导入/导出。
- 增强 CSV 空单元格兼容性，并确保导入异常后恢复界面加载状态。
- 增加图片及画布尺寸校验，避免异常图片触发除零或无效缩放。
- 同步版本元数据与测试，新增 CSV、标签分类和渲染边界回归测试。
- 保留 v3.5 原目录与发布包，3.6 以独立目录发布。

v3.5
- 采用模块化目录发布，并提供独立入口与 README。
- 完善帧序列浏览、质检、CSV 数据处理及打包运行结构。

v3.4
- 延续模块化架构，优化发布包内容与运行稳定性。

v3.3
- 完善模块拆分后的功能衔接、资源组织与界面交互。

v3.2（模块化）
- 继续拆分界面、数据和业务逻辑，降低单文件维护成本。

v3.1（模块化）
- 将单文件工具迁移到模块化工程结构。

v3.0（模块化）
- 完成主要架构重组，形成可打包的模块化版本。
